Permisos de Android

Cómo interpretar las solicitudes de acceso de una aplicación.

¿Qué es un permiso?

Android utiliza permisos para controlar el acceso de las aplicaciones a determinadas funciones o datos del dispositivo. Algunas solicitudes aparecen durante la instalación y otras cuando una función intenta utilizarlas.

Cómo evaluar una solicitud

Pregúntate qué función estás intentando utilizar y si el permiso parece necesario para esa función. Una aplicación multimedia puede necesitar ciertos accesos dependiendo de cómo gestione archivos o contenido, pero no debes aceptar solicitudes que no entiendas.

¿Puedo cambiar permisos?

En versiones modernas de Android puedes revisar permisos desde Ajustes > Aplicaciones > GADS PRO > Permisos, aunque los nombres exactos pueden variar según el fabricante.

Si algo no funciona

Si una función necesita un permiso que rechazaste, Android puede impedirle trabajar. Revisa el permiso concreto y concede acceso únicamente si comprendes por qué se necesita.
