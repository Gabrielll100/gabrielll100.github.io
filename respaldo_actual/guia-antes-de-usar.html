GADS PRO: qué conviene resolver antes de usarlo

Una página de descarga no debería obligar al visitante a instalar una aplicación sin información previa. Por eso GADS PRO reúne en un mismo sitio una explicación del proyecto, capturas, tutorial, requisitos, solución de problemas, preguntas frecuentes y documentos legales.

Qué información ofrece este sitio

La página principal explica qué es el proyecto y para quién está pensado. También muestra capturas para que el visitante pueda reconocer la interfaz y un tutorial que sirve como referencia visual.

Por qué revisar las capturas

Las imágenes permiten comparar lo que esperas encontrar con lo que aparece después de instalar. También ayudan a una persona que necesita instrucciones visuales y no quiere comenzar el proceso sin conocer la interfaz.

Por qué existe una guía escrita

Un video es útil, pero no siempre es suficiente. Una persona puede querer buscar una respuesta concreta, como “qué hago si no instala” o “qué debo revisar antes de abrir una APK”. Por eso el sitio incluye explicaciones escritas que se pueden consultar directamente.

Qué hacer si encuentras un error

La mejor información para solicitar soporte es el modelo del dispositivo, versión de Android, versión de la aplicación, mensaje de error y pasos que provocaron el problema. Con esos datos es más sencillo reproducir una incidencia.

Información que puede cambiar

Las aplicaciones evolucionan. Un requisito, enlace o característica puede cambiar con una nueva versión. Por eso esta web debe considerarse una fuente de referencia que se actualiza cuando el proyecto modifica sus recursos.

Transparencia: ninguna página puede garantizar que una aplicación funcione en todos los teléfonos. La compatibilidad depende de la versión de Android, el dispositivo y la versión concreta de la aplicación.
