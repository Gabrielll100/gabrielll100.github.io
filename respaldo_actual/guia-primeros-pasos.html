Primeros pasos

Una ruta sencilla para conocer la aplicación después de instalarla.

1. Abre la aplicación

Comprueba que la pantalla principal se carga correctamente y familiarízate con la navegación.

2. Explora las secciones

Visita las categorías disponibles y observa dónde están las opciones principales. No es necesario activar todos los permisos de inmediato.

3. Prueba la búsqueda

Introduce una consulta y comprueba cómo responde la aplicación. Si una búsqueda depende de Internet, verifica primero la conexión.

4. Revisa la configuración

Comprueba las opciones disponibles y utiliza únicamente las funciones que comprendas.

5. Reporta problemas con contexto

Un buen reporte incluye qué hiciste, qué esperabas que ocurriera y qué sucedió realmente. Añade modelo y versión de Android cuando sean relevantes.
