Diagnóstico paso a paso de problemas en Android

Un método para investigar un problema sin asumir la causa antes de comprobarla.

1. Describe exactamente qué ocurre

“No funciona” es demasiado amplio para encontrar una solución. Anota qué pantalla estabas usando, qué acción realizaste, qué esperabas y qué ocurrió realmente. Si aparece un mensaje del sistema, copia su texto exacto.

2. Determina si el problema es local o externo

Si una función necesita Internet, comprueba otra aplicación o página. Si todo lo demás funciona, el problema puede estar limitado a la aplicación o al servicio utilizado. Si varias aplicaciones fallan, investiga primero la conexión del dispositivo.

3. Comprueba la versión

Anota la versión de Android y la versión de GADS PRO instalada. Una actualización del sistema o de una aplicación puede cambiar permisos, compatibilidad o comportamiento. No mezcles varias versiones durante una prueba porque dificulta saber qué produjo el cambio.

4. Haz una sola modificación cada vez

Si cambias permisos, borras datos, reinstalas y reinicias al mismo tiempo, no sabrás qué acción resolvió el problema. Haz una prueba, observa el resultado y registra el cambio.

5. Revisa almacenamiento y permisos

El espacio insuficiente puede impedir descargas o instalaciones. Los permisos pueden limitar funciones concretas. Comprueba ambos antes de asumir que existe un fallo de la aplicación.

6. Repite el escenario

Un error que aparece una vez puede ser temporal. Repite exactamente los mismos pasos y observa si ocurre siempre, ocasionalmente o solo bajo determinadas condiciones.

7. Prepara un reporte útil

Un buen reporte incluye modelo del dispositivo, versión de Android, versión de la aplicación, pasos para reproducir el problema, mensaje de error y si el problema aparece con Wi‑Fi, datos móviles o ambos.

Privacidad: nunca incluyas contraseñas, códigos de acceso, documentos personales o información sensible en un reporte.
