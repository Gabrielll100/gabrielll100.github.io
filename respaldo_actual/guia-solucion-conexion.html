Qué revisar cuando una aplicación no carga contenido

Pasos de diagnóstico para diferenciar un problema de conexión, servidor, aplicación o dispositivo.

Empieza por identificar el alcance

Comprueba si otras páginas o aplicaciones tienen Internet. Si todo lo demás funciona, el problema puede estar limitado a una función concreta.

Comprueba la conexión

Cambia entre Wi‑Fi y datos móviles si tienes ambas opciones disponibles. Evita realizar muchas pruebas simultáneas porque pueden dificultar saber qué cambio produjo el resultado.

Reinicia la aplicación

Cierra la aplicación completamente y vuelve a abrirla. Si el problema continúa, reinicia el dispositivo para descartar un estado temporal.

Revisa si existe una actualización

Una función puede dejar de funcionar después de cambios en un servicio externo. Consulta la página de actualizaciones del proyecto para comprobar si hay información nueva.

Cuándo reportarlo

Si el problema continúa, anota el modelo del dispositivo, la versión de Android, la versión de GADS PRO y qué pantalla produce el error. Esa información es mucho más útil que un mensaje como “no funciona”.

No compartas contraseñas, códigos de acceso ni datos personales al reportar un problema.
