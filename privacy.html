Política de Privacidad

Última actualización: 26 de agosto de 2026

Esta página explica de forma general qué información puede tratar el sitio. Debe ajustarse antes de publicar servicios que recopilen datos adicionales.

Datos proporcionados por el visitante

Si contactas con el proyecto por correo u otro canal, la información que envíes se utilizará para atender la consulta. No solicitamos datos que no sean necesarios para responder.

Datos técnicos

El alojamiento web y los servicios de terceros pueden procesar información técnica como dirección IP, navegador, dispositivo, fecha y solicitudes realizadas. El alcance exacto depende del proveedor utilizado.

Publicidad y analítica

Si se incorporan Google AdSense, Analytics u otros servicios, esta política deberá actualizarse para describirlos correctamente, incluyendo cookies, identificadores, finalidades y opciones de privacidad aplicables.

Enlaces externos

Los enlaces externos llevan a sitios que tienen sus propias políticas. Revisa sus condiciones antes de compartir información.

Contacto

Para consultas de privacidad, utiliza el canal de contacto publicado en el sitio.

Criterio práctico para este caso

Antes de cambiar una configuración relacionada con Política de Privacidad, conviene identificar el resultado que se busca y establecer una forma sencilla de comprobarlo. Esto evita aplicar cambios innecesarios y permite volver atrás si el resultado no es el esperado.

Antes

Define el síntoma y las condiciones en las que aparece.

Durante

Haz un cambio cada vez y anota qué ocurrió.

Después

Repite la prueba y compara el resultado.

Límites y variaciones

La interfaz puede cambiar según fabricante, versión de Android, modelo y aplicación. Si el nombre de una opción no coincide con el de esta guía, busca el concepto equivalente en la configuración del dispositivo y contrástalo con la documentación oficial.
