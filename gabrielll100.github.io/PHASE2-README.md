## Cómo añadir una imagen
1. Coloca el archivo en `media/imagenes/`.
2. Usa una imagen propia o con licencia adecuada.
3. Añade un `<figure>` en `multimedia.html` con `alt` descriptivo.
4. Explica debajo qué demuestra la imagen y por qué es útil.

## Cómo añadir un video de YouTube
1. Copia el ID del video, por ejemplo `ABC123`.
2. En `multimedia.html`, usa `https://www.youtube.com/embed/ABC123`.
3. Escribe un párrafo propio antes o después del reproductor.
4. Explica qué aprenderá el usuario y enlaza a una guía relacionada.

## Importante para AdSense
Los videos e imágenes deben complementar el contenido. No conviene crear páginas compuestas casi únicamente por embeds o galerías. Google señala que el sitio debe aportar contenido original, relevante y suficiente, y que el contenido externo debe incluir valor añadido como comentario, explicación o curación.
