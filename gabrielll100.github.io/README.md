# GADS PRO — versión Pro orientada a contenido útil

Esta versión reorganiza el sitio para priorizar contenido original, navegación clara y transparencia.

## Antes de publicar
1. Revisa que el dominio/canonical coincida con el dominio real.
2. Configura un correo real en `contacto.html`.
3. Revisa `privacy.html` y `cookies.html` para que describan los servicios realmente usados.
4. No publiques afirmaciones que la app no pueda demostrar.
5. Verifica todos los enlaces y descargas.
6. Si usarás AdSense, añade el código oficial generado por tu cuenta sin modificarlo y revisa las políticas vigentes.

## Estructura
- `index.html`: portada editorial.
- `guias.html`: biblioteca de contenido.
- `buscar.html`: buscador interno.
- `app.html` / `download.html`: información y descarga.
- `privacy.html`, `cookies.html`, `terms.html`, `contacto.html`: confianza y transparencia.
- `style.css`: diseño compartido.

## Importante
No existe una cantidad mágica de palabras que garantice AdSense. La calidad, originalidad, utilidad, navegación y cumplimiento de políticas son más importantes que rellenar páginas.
