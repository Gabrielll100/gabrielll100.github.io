Contacto con GADS PRO

Este canal está pensado para comunicar errores, enlaces rotos, información desactualizada o problemas de funcionamiento del sitio.

Qué incluir en un reporte

  • La URL exacta de la página.
  • Una descripción breve de lo que ocurrió.
  • Los pasos necesarios para reproducir el problema.
  • Si corresponde, modelo del dispositivo y versión de Android.
  • Una captura de pantalla únicamente si no contiene datos privados.

Qué no debes enviar

No envíes contraseñas, códigos de acceso, claves API privadas, documentos de identidad, información bancaria ni otros datos sensibles.

Canal de contacto

El responsable del proyecto puede publicar aquí un correo dedicado para soporte cuando esté configurado. Mientras tanto, no se muestra una dirección inventada ni se solicita información personal innecesaria.

Correcciones de contenido

Si una guía contiene un dato que ya cambió, una URL dejó de funcionar o una explicación necesita actualización, indica la página y el dato concreto. Esto facilita revisar la información sin pedir datos personales.
