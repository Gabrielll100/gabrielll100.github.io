Capturas y demostraciones

Cómo utilizar las imágenes del sitio para conocer la interfaz antes de instalar.

Qué muestran las capturas

Las capturas sirven para anticipar la organización visual de una versión concreta. Pueden mostrar navegación, reproducción, búsqueda o pantallas de configuración.

No sustituyen la documentación

Una imagen puede cambiar entre versiones. Por eso cada captura debe acompañarse de texto que explique qué se está mostrando y cuándo puede diferir de la versión actual.

Cómo aprovecharlas

Antes de instalar, compara la interfaz que esperas encontrar con las imágenes publicadas. Después de instalar, puedes utilizarlas como referencia para localizar funciones.
