Solución de problemas de reproducción

Lista de comprobación para diagnosticar problemas habituales al visualizar contenido multimedia.

Si el contenido no carga, comienza por comprobar la conexión. Después revisa si otras páginas o aplicaciones funcionan correctamente. Si todo lo demás funciona, reiniciar la aplicación puede ayudar a descartar un fallo temporal.

Comprueba también el espacio disponible del dispositivo y si existe una actualización de la aplicación o del sistema. Cuando el problema aparece únicamente en una pantalla o dispositivo, compara con otro entorno para identificar si se trata de compatibilidad.

Si la reproducción comienza pero se interrumpe, revisa la estabilidad de la red y prueba una calidad de reproducción menor. Si el problema persiste, anota el modelo del dispositivo, versión del sistema y pasos que producen el error; esa información hace que una consulta de soporte sea mucho más útil.
