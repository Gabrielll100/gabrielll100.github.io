CONTROL DE CALIDAD

Checklist de calidad para cada nueva URL

La página se considera lista cuando puede aportar valor aunque el visitante no pulse un anuncio, enlace externo o descarga.

Contenido

  • ☐ Responde una pregunta concreta
  • ☐ La explicación es propia y sustancial
  • ☐ Incluye pasos accionables cuando corresponde
  • ☐ Incluye errores frecuentes
  • ☐ Incluye checklist o criterio de verificación
  • ☐ Incluye solución o siguiente paso
  • ☐ Tiene enlaces internos relacionados

SEO técnico

  • ☐ Título claro
  • ☐ Meta descripción descriptiva
  • ☐ URL corta y coherente
  • ☐ Canonical correcta
  • ☐ En sitemap si es indexable
  • ☐ Página 404 útil

Multimedia

  • ☐ Imágenes con alt descriptivo
  • ☐ SVG con title y description accesibles
  • ☐ Vídeo externo acompañado de explicación propia
  • ☐ Recurso externo con contexto y enlaces relacionados

Seguridad

  • ☐ No se pide desactivar protecciones sin una razón legítima
  • ☐ No se prometen resultados no demostrados
  • ☐ Fuentes relevantes identificadas
  • ☐ Fecha de revisión cuando el tema cambia con frecuencia

Criterio práctico para este caso

Antes de cambiar una configuración relacionada con Checklist de calidad de páginas, conviene identificar el resultado que se busca y establecer una forma sencilla de comprobarlo. Esto evita aplicar cambios innecesarios y permite volver atrás si el resultado no es el esperado.

Antes

Define el síntoma y las condiciones en las que aparece.

Durante

Haz un cambio cada vez y anota qué ocurrió.

Después

Repite la prueba y compara el resultado.

Límites y variaciones

La interfaz puede cambiar según fabricante, versión de Android, modelo y aplicación. Si el nombre de una opción no coincide con el de esta guía, busca el concepto equivalente en la configuración del dispositivo y contrástalo con la documentación oficial.
