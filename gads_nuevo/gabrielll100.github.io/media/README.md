# Biblioteca multimedia de GADS PRO

Coloca aquí recursos propios del proyecto.

- `media/imagenes/`: capturas de pantalla, diagramas, fotografías y gráficos propios.
- `media/videos/`: videos propios si decides alojarlos localmente.

Para videos de YouTube, no hace falta descargar el video: usa su ID en `multimedia.html` y añade alrededor del reproductor una explicación original, pasos y conclusiones.

Recomendación editorial: cada imagen o video debe ayudar a explicar algo concreto. No publiques galerías o embeds sin contexto únicamente para llenar espacio.
