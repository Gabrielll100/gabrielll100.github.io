Glosario Android

Conceptos básicos explicados sin tecnicismos innecesarios.

APK

Formato de paquete utilizado para distribuir e instalar aplicaciones Android.

Permiso

Autorización que una aplicación puede solicitar para acceder a una función o recurso del dispositivo.

Caché

Datos temporales que una aplicación guarda para acelerar determinadas operaciones. Borrarlos puede solucionar algunos problemas, pero no todos.

Compatibilidad

Conjunto de condiciones que permiten que una aplicación funcione correctamente en un dispositivo concreto.

Fuente desconocida

Origen que Android no considera una tienda o fuente previamente autorizada. Habilitar instalaciones desde una fuente requiere especial cuidado.

Versión

Identificador que permite distinguir una edición de una aplicación de otra.

Almacenamiento

Espacio disponible para archivos y aplicaciones. Tener muy poco espacio puede provocar errores.

Permisos especiales

Accesos que requieren controles adicionales en Android y que deben revisarse con atención.

GADS PRO

Proyecto independiente centrado en aplicaciones, Android, instalación responsable y guías prácticas. El objetivo es explicar antes de pedir al visitante que descargue o instale algo.
