Cómo usar capturas de pantalla para diagnosticar un problema

Contenido originalRevisión: 2026-08-26

Qué debe mostrar una captura para ser útil y cómo evitar exponer datos personales.

Respuesta rápida: Una buena captura conserva el mensaje relevante y elimina información sensible que no sea necesaria para el diagnóstico.

Por qué importa

Una buena captura conserva el mensaje relevante y elimina información sensible que no sea necesaria para el diagnóstico. Este enfoque evita decisiones automáticas y ayuda a separar un problema real de una señal que solo parece preocupante.

Pasos recomendados

1

Captura el estado relevante

Incluye el mensaje, botón o pantalla que explica el problema.

2

Recorta lo innecesario

Reduce elementos que distraen del fallo.

3

Oculta datos personales

Tapa correos, números, códigos y nombres si no son necesarios.

4

Añade contexto por escrito

Explica qué hiciste antes de la captura.

5

Numera varias capturas

Si hay una secuencia, usa 1, 2, 3 y descríbela.

Errores frecuentes

  • Publicar códigos o correos: Una captura puede contener información privada.
  • Enviar solo una imagen sin explicación: El contexto sigue siendo necesario.

Checklist antes de darlo por resuelto

  • ☐ La captura muestra el error
  • ☐ El contexto está escrito
  • ☐ Oculté datos sensibles
  • ☐ Las imágenes están ordenadas
  • ☐ No incluí códigos privados

Si el problema continúa

Documenta modelo del teléfono, versión de Android, versión de la aplicación, conexión utilizada y mensaje exacto. No borres datos ni cambies varios ajustes a la vez: hacerlo dificulta saber qué acción solucionó o provocó el problema.
