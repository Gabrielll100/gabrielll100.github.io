Solución de problemas

Procedimiento ordenado para diagnosticar fallos sin borrar datos innecesariamente.

1. La aplicación no instala

Comprueba que el archivo sea compatible, que la descarga esté completa y que exista almacenamiento suficiente. Si Android muestra un mensaje concreto, anótalo antes de buscar una solución.

2. La aplicación se cierra

Reinicia el dispositivo y prueba de nuevo. Si el fallo se repite, revisa la versión de Android y si existe una versión más reciente de la aplicación.

3. No carga contenido

Comprueba Internet. Después prueba otra red para descartar un problema de conectividad. Si otras aplicaciones funcionan y solo GADS PRO falla, el problema puede estar relacionado con esa función.

4. El vídeo no reproduce

Comprueba conexión, volumen y compatibilidad. Si el contenido depende de un servicio externo, una interrupción de ese servicio puede afectar la reproducción.

5. Cuándo contactar

Si el problema continúa, contacta al proyecto indicando modelo del dispositivo, versión de Android, versión de GADS PRO y pasos exactos para reproducir el fallo. No envíes contraseñas ni datos personales innecesarios.
